# Datos

El dataset de visitas todavía no está definido.

- Documentar aquí la fuente, licencia/permiso, columnas y limitaciones.
- Los datos sintéticos deben etiquetarse claramente como sintéticos.
- No guardar ni subir datos personales identificables de clientes sin autorización.
- Los archivos locales de `raw/` y `processed/` se excluyen de Git por defecto. Si se acuerda compartir un dataset sintético, documentar la decisión y quitar la exclusión específica de forma deliberada.
